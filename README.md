# AI Integration Project

Welcome to the **AI Integration Project**! This repository demonstrates how to integrate various Artificial Intelligence APIs into your Python projects. Currently, it features examples using **Google GenAI (Gemini)** and **Hugging Face**.

## Project Structure

The project is divided into two main components:
1. `AIDockerTutor/` - A conversational AI script using Google GenAI (Gemini).
2. `HuggingFaceAI/` - Scripts for NLP tasks utilizing the Hugging Face Inference API.
